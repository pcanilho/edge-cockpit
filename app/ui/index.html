Something wrong?

Report a problem saves a report file and opens the bug form on GitHub, filled in. Nothing leaves this PC unless you post it. The file is plain text: read it first if you like.

It holds the app, Windows and game versions, your screens and their scale, the keybind check, your settings and the last 300 Game.log lines the console read, with your handle, other players' names, ID numbers and addresses taken out.
