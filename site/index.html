What it does

Follows the game

It reads the game's log while you play. Board a ship and its page opens in the maker's colours, with its outline, role and quantum target. Step out and you get On foot. Go down and a big revive button is waiting.

A page for each role

A target dial for fighters, a laser power knob for miners, a beam head for salvage, a tractor beam slider for cargo. Every ship page also has power, flight and gear plates and one big Flight Ready button. No key appears twice on a page.

Knows where you stand

Your location, mission objective and contract rewards sit on a glass display. Weapons grey out in armistice zones. The frame goes red only for a CrimeStat or a disabled ship. Nothing is guessed: a switch the game doesn't report stays a push-button.

Your keys, not new ones

It reads your actionmaps.xml, so keys you rebound in game just work. The game keeps focus while you tap. Settings lists any key the console can't press.

  • Out of the wayStarts with Windows and waits in the tray. The screen goes dark when you quit and wakes when the game starts.
  • Your layoutLong-press a plate's title, drag the plates, tap Done. The order is kept for each role.
  • Night modeOn, off, or automatic from 20:00 to 07:00.
  • Updates when you're dockedA new release is offered with its notes, and only while you're not playing.
  • LightA 1.5 MB installer. Nothing animates while the console is idle.
  • No accidentsEject is a slide and self-destruct sits under a red cover, so neither fires on a stray tap.

Install

  1. Download and run the installer Windows SmartScreen will warn, because the app isn't code signed. Click More info, then Run anyway.
  2. Pick the control profile In game: Options › Keybindings › Advanced Controls Customization › Control Profiles. Choose xeneon and tick only Keyboard. This gives the console's extra actions a free key. Your own binds stay as they are.
  3. Launch Star Citizen The console wakes, finds the touchscreen and opens the right page.

Questions

Do I need a Xeneon Edge?

It's the only screen fully supported for now. The console scales to fit other touchscreens, and layouts for other sizes come on request: ask for your device.

Is it safe to use with the game?

It works like a second keyboard. It sends key presses and reads Game.log, a text file the game writes. It doesn't read game memory, inject anything or change game files.

Does it take focus from the game?

No. The window never becomes active, so your mouse and keyboard stay in the game while you tap.

Does it cost anything?

No. It's free and MIT licensed, with no account, ads or tracking. Sponsoring is optional.

What does it connect to?

FleetYards.net, once per ship, for its outline, which is then kept on your PC. GitHub, to check for updates. Nothing else.

Which game version does it support?

The current live build. Each release says which game build it was tested on.

Something doesn't work. Where do I report it?

Open an issue. The bug form asks for what's needed, such as the game build and your screen.
