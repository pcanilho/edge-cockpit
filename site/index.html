What it does

Follows the game

Reads Game.log as you play. Board a ship and its page opens with the ship's render, role and quantum target. Ships from nine makers get the maker's plates and trim. Step out for On foot. Go down and a revive button is waiting.

Any screen in the house

Turn on Devices in Settings and scan the code with a phone. No app to install. A phone shows one plate at a time, sized for a thumb, upright or sideways; a tablet or another PC shows the whole console. Give a device one plate, or move a plate off the Edge onto it.

A page for each role

Target dial for fighters, laser power knob for mining, beam dial for salvage, tractor beam slider for cargo. Every ship page also has power, flight and gear plates and a Flight Ready button.

Pages of your own

Duplicate a ship page or start blank, then drag keys, switches, rockers, covers and screens onto the plates. The editor only offers what fits: a switch takes actions with set-on and set-off binds, an eject key needs a cover. Link a page to your ships, preview it on a phone, share it as a file. The curated pages stay as they are.

Knows where you stand

Location, mission objective and rewards on the status display. Weapons grey out in armistice zones. The frame turns red only for a CrimeStat or a disabled ship. No guessed state: switches stay unlit and the gear lever stays centred until you set them. If a patch changes the log lines it reads, an amber chip says so.

Session log

Time played, kills, times downed, missions and ships flown. Also who downed you last and with what, region and shard, last system jump, finished refinery jobs and a timeline.

The world around you

Executive hangar cycle (sync it once at the lights), keycard printer and Ruin vault door timers, and RSI server status. Commodities start where you are: what this place buys and sells, the best place in the system for each, and reported stock. Prices are player reports from UEX, each with its age. If the console doesn't know where you are, Locate (on foot) opens your inventory for a moment so Game.log names the place.

Your keys, not new ones

Reads your actionmaps.xml, so rebound keys just work. The game keeps focus while you tap. A setup check on first start shows what's ready; Settings lists any key it can't press. Large labels for glare or distance.

Install

  1. Download and run the installer SmartScreen warns because the app isn't code signed: More info, then Run anyway.
  2. Pick the control profile In game: Options › Keybindings › Advanced Controls Customization › Control Profiles. Pick edge-cockpit, tick only Keyboard. This binds actions that have no default key. Your own binds stay.
  3. Launch Star Citizen The console wakes on the touchscreen and opens the right page.

Questions

Do I need a Xeneon Edge?

It's the only screen fully supported. The console scales to other touchscreens, and layouts for other sizes come on request: ask for your device. Phones, tablets and other PCs on your network can join as extra screens from Settings › Devices.

Is it safe to use with the game?

It works like a second keyboard: it sends key presses and reads Game.log, a text file the game writes. It doesn't read game memory, inject code or change game files. It only adds its keybind profile to the game's keybind folder.

Does it take focus from the game?

No. The window never becomes active, so mouse and keyboard stay in the game.

Does it cost anything?

No. Free, MIT licensed, no account, ads or tracking. Sponsoring is optional.

What does it connect to?

FleetYards.net, once per ship, for its outline and render (kept on your PC). GitHub, for updates. While the World page is open: UEX for prices (every 30 min) and RSI's status page (every 5 min). With Devices on, it serves the console on your home network (port 47823, private addresses only) and only paired devices can press keys. Nothing else.

Which game version does it support?

The current LIVE build. Each release notes the game build it was tested on.

Something doesn't work. Where do I report it?

Open a bug report. The form asks for what's needed.
